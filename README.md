# Analisis Pendapatan Tahun 2024 dan 2025


Notebook Python sederhana untuk melakukan analisis data transaksi POS tahun 2024–2025.


Mulai dari proses pembersihan data, identifikasi data anomali, perhitungan pendapatan setelah diskon, hingga visualisasi perbandingan pendapatan setiap tahun menggunakan Python dan Pandas.


## Hasil Perhitungan

| 2024 | Rp 133.840.400 |
| 2025 | Rp 140.638.800 |
